# Sicurezza

Non pubblicare vulnerabilità non corrette in una issue pubblica. Finché non è configurato un
indirizzo dedicato, usa la funzione **Private vulnerability reporting** del repository
GitHub. Se non è disponibile, apri una issue priva di dettagli sfruttabili chiedendo un
canale privato.

Includi versione, Android, impatto, prerequisiti e una riproduzione minima senza dati reali.
Non inviare chiavi private, PIN, messaggi o archivi personali.

La versione alpha non è auditata e non deve essere usata per comunicazioni ad alto rischio.
I limiti noti sono elencati in `docs/LIMITATIONS.md`.
