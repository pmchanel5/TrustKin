# Development Progress Notes

This folder records implementation details that explain how Brotherhood features were built and verified.

Use it as a handoff/reference area for future agents and developers:

- `MVP_alpha/kr*.md` maps completed OKR key results to code, behavior, verification, and follow-up risks.
- Files here should describe implementation reality, not desired future behavior.
- When a key result is checked in `docs/MVP_alpha/okr_mvp_alpha.md`, add or update its matching progress note.
- Keep notes concise but specific enough for another agent to locate the relevant code and tests quickly.

Do not use this folder as a replacement for tests, source comments, or user-facing documentation. It is a development trail for understanding decisions and current state.
